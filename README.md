# zero-to-tech

《零到全栈》课程项目 —— 我的第一个网页

## 文件结构

| 文件 | 职责 |
|---|---|
| index.html | 页面结构（HTML 标签，以及对 CSS / JS 文件的引用） |
| style.css | 样式（外观：颜色、布局、字体） |
| script.js | 交互逻辑（点击按钮后改变文字） |

## 如何运行

直接用浏览器打开 `index.html` 即可，无需安装任何东西、无需服务器。

## 模块进度

- 模块 3.1：写出单文件网页（HTML + CSS + JS 混在一个文件里）
- 模块 3.2：拆分为三个文件（当前状态）

## 验证要点

刷新页面后，外观与行为应和拆分前完全一致：

- 浅灰色背景，内容在白色卡片里
- 点击「点我试试」按钮，文字发生变化
- 如果变成白底黑字，检查 `index.html` 里引用的文件名是否与 `style.css` / `script.js` 完全一致
